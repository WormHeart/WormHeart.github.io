配置 Debian Server

一、安装Debian系统

  1. 下载Debian镜像：访问Debian官网，下载最新的Debian 12镜像。
  2. 制作启动U盘：使用工具（Rufus）将下载的镜像文件写入U盘，制作成启动盘。
  3. 启动安装：通过U盘启动计算机，进入BIOS，然后到Debian安装界面。
  4. 设置系统：按照提示进行设置。
    1. 安装非图形化界面
    2. 不需要进行网络配置，等安装好系统后在进行网络配置
    3. 安装ssh server（也可以等安装后，再下载配置）
    4. 除了一个启动磁盘自动分区外，其他磁盘不需要挂载
